# Focus V3

Focus V3 — это модернизированное приложение для отслеживания привычек и задач, написанное на React. Оно помогает систематизировать повседневные дела, развивать полезные привычки и видеть свой прогресс.

## Чем отличается от Focus V2

- Написано на React (вместо ванильного JS).
- Использует роутер для навигации между страницами.
- Новая цветовая палитра (тёмная/светлая тема).
- Добавлены категории, приоритеты и инструкции по постановке задач.

## Функциональность

- Отслеживание привычек с добавлением, удалением и переключением статуса.
- Список задач с категориями («Работа», «Учёба», «Личное») и приоритетами (высокий, средний, низкий).
- Фильтрация задач по категориям.
- Прогресс-бар выполнения задач.
- Слайдер с чекбоксами для отметки выполнения привычек по месяцам.
- Адаптивный дизайн и бургер-меню для мобильных устройств.
- Сохранение данных в localStorage.

## Технологии

- React
- React Router
- CSS (переменные, адаптив)
- localStorage
